UNIDAD 13

DOM (Document Object Model)

Con el DOM puedo cambiar la página desde JavaScript: seleccionar elementos, modificar su texto y su estilo, y crear elementos nuevos. Cada botón ejecuta lo que en la consigna se hacía por consola.

querySelector() textContent classList createElement()

Ejercicios

Manipular Texto Y Contenido

Arranco con un título <h1> solo. Desde JavaScript le cambio el texto, después lo reemplazo por un párrafo y al final agrego otro párrafo más.

Soy un título

¡Shuffle!

Dos <div>, uno con ID source y otro con ID destination. Los guardo en variables e intercambio el texto de uno con el del otro.

div#source
Hola, soy el texto de SOURCE
div#destination
Y yo soy el texto de DESTINATION

Manipular CSS

Un <div> que arranca sin estilo (por eso no se ve). Primero le doy alto, ancho y color con la propiedad style, y después hago lo mismo con la clase .square usando classList. El último paso le pone y le saca la clase cada un segundo con setInterval().

¿Qué devuelve div.classList? Devuelve un DOMTokenList, que es una lista con todas las clases que tiene el elemento en ese momento.

Formulario E Input

En el HTML este espacio está vacío: todo el formulario lo crea JavaScript con createElement() y appendChild(). Completalo y tocá el botón para leer los datos desde JavaScript.
