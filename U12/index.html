UNIDAD 12

Object data type

Los objetos guardan datos en pares de clave y valor. Practiqué cómo crearlos, leerlos, modificarlos, recorrerlos y combinarlos con arreglos.

objetos for...in dot y bracket notation arreglos de objetos

Ejercicios

Registro En P5

Un objeto con las propiedades que tiene cada usuario nuevo que se registra en P5: usuario, edad, dirección, fecha de nacimiento y contraseña.

Variable miAuto

Arranco con un objeto vacío y le voy agregando propiedades de distintas formas: con punto, con corchetes y usando variables como clave. Al final lo recorro con for...in.

Para pensar: miAuto[propertyKey] y miAuto["modelo"] devuelven lo mismo (el modelo), porque la variable propertyKey guarda el string "modelo". Con miAuto[nextProperty] y miAuto["color"] pasa igual: las dos devuelven el color.

Aumentar La Nota

Recorro un arreglo de estudiantes y a los que tienen más de 5 les subo 2 puntos, cuidando que la nota no pase de 10.

Base De Datos De Películas

Un arreglo de películas donde cada una es un objeto con título, rating y si la vi o no. Con un for armo una frase para cada una.

Números Duplicados

Cada número del arreglo pasa a ser una propiedad del objeto, y su valor es ese número multiplicado por dos.

Desafío + 27 🎂

Con .filter() me quedo con las personas que tienen más de 27 años.

Camino Al Oscar

Varios pasos mezclando arreglos y objetos: separo los actores que tienen nombre o apellido con vocal, recorro un objeto para sacar actores y películas, y armo un objeto nuevo con las películas de cada actor.

Posición Adecuada

Ordeno un arreglo de personas de menor a mayor por edad y a cada una le agrego la propiedad posicion.

🚀 Software Factory

Un cliente quiere saber cuánto vale el stock de cada producto. La función recibe el arreglo de productos y devuelve uno nuevo con el nombre y el valor total (precio x cantidad de artículos).

🚀 Contar caracteres

contarCaracteres recibe una palabra y devuelve un objeto que dice cuántas veces aparece cada letra.
